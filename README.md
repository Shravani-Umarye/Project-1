<h1>Project 1: Group Expense Splitter</h1>
<p><b>Full Stack Web Application</b></p>

<h3>Description</h3>
<p>A web-based application that allows users to manage and split expenses within a group. It helps track shared expenses and calculate how much each member owes.</p>

<h3>Features</h3>
<ul>
  <li>Add and manage group members</li>
  <li>Record expenses with details</li>
  <li>Automatically calculate expense distribution</li>
  <li>Display final settlement results</li>
</ul>

<h3>Technologies Used</h3>
<ul>
  <li>Frontend: HTML, CSS, JavaScript</li>
  <li>Backend: PHP</li>
  <li>Database: MySQL</li>
</ul>
